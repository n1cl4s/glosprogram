# UC3: Visa vilka språkpar som finns

**Som** användare **vill jag** se vilka språkpar som går att välja när programmet startar, **så att** jag vet vilka översättningar som finns.

## Var i koden
`Program.cs`, efter inläsningen och före huvudloopen.

## Klart när
- [x] Programmet skriver ut en numrerad lista över språkparen, till exempel `1. swedish → english` och `2. swedish → german`.
- [x] Listan kommer från datan, inte från hårdkodad text.
- [x] Språkparen visas i samma ordning varje gång, till exempel i bokstavsordning, så att ett nummer alltid betyder samma par (se [BUG7](../bugs/BUG7-filordning-inte-bestamd.md)).
